# Bikeshare project

## Date created
The project was originally created in *December 2025*, then this local repository (along with this README file) was created on *14th January 2025*.

## Description
This project provides *insights on bikesharing trends* across several US cities, using real bikesharing data.
The project creates an interactive user experience in the terminal, prompting the user to choose city, month and day from a list of options.
It then displays a range of output metrics on popular travel times and station, travel duration and users.
Finally, it gives the user to see rows of raw data, then an option to restart the process.

## Files used
Used multiple csv files of city-specific bikeshare data.
